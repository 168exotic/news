## ข่าวเตือนภัยการฉ้อโกง

รวมประเด็นข่าวและรูปแบบการหลอกลวงที่ควรติดตาม เพื่อนำไปเผยแพร่ต่ออย่างมีแหล่งอ้างอิง:

1. **หลอกลงทุนผลตอบแทนสูง** — มิจฉาชีพใช้ชื่อบริษัทหรือบุคคลมีชื่อเสียง ชวนลงทุนผ่านโซเชียลมีเดียและเร่งให้โอนเงิน ควรตรวจสอบผู้ให้บริการกับ [สำนักงาน ก.ล.ต.](https://www.sec.or.th/)
2. **แก๊งคอลเซ็นเตอร์ปลอมเป็นธนาคารหรือตำรวจ** — อ้างว่าบัญชีมีปัญหาหรือเกี่ยวข้องกับคดี แล้วขอรหัส OTP ให้ติดตั้งแอป หรือให้โอนเงินไป “ตรวจสอบ” หน่วยงานจริงจะไม่ขอข้อมูลลับหรือให้โอนเงินในลักษณะนี้
3. **SMS และเว็บไซต์ฟิชชิง** — ส่งลิงก์ปลอมให้กรอกชื่อผู้ใช้ รหัสผ่าน หรือข้อมูลบัตร ควรเข้าเว็บไซต์หรือแอปทางการด้วยตนเองแทนการกดลิงก์
4. **ซื้อขายออนไลน์แล้วไม่ส่งสินค้า** — ตรวจสอบประวัติร้านค้า ใช้วิธีชำระเงินที่มีการคุ้มครองผู้ซื้อ และเก็บหลักฐานการสนทนา/การโอนเงินไว้เสมอ
5. **หลอกให้รักแล้วขอเงิน (Romance scam)** — สร้างความสัมพันธ์ออนไลน์ก่อนขอยืมเงินหรือชวนลงทุน ไม่ควรโอนเงินให้คนที่ยังไม่เคยพบตัวจริง

หากตกเป็นผู้เสียหาย ให้หยุดการโอนเงิน ติดต่อธนาคารทันที เก็บหลักฐาน และขอคำแนะนำจาก **สายด่วน AOC 1441** หรือแจ้งความออนไลน์ผ่าน [ตำรวจไซเบอร์](https://www.thaipoliceonline.go.th/) โดยตรวจสอบช่องทางทางการก่อนทุกครั้ง

> ก่อนโพสต์ข่าว ควรตรวจสอบวันที่ เนื้อหา และแหล่งข่าวจากหน่วยงานที่เกี่ยวข้อง เพื่อไม่ส่งต่อข้อมูลเท็จหรือกล่าวหาบุคคลโดยไม่มีหลักฐาน
